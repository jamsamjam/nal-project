# DCN Visualization

Interactive ns-3-based framework for visualizing and analyzing data center network behavior.

The system supports configurable 1-layer, 2-layer, and 3-layer topologies, workload-driven traffic generation, TCP congestion control algorithms (NewReno, Cubic, DCTCP), and queue algorithms (FIFO, RED). Packet-level traces generated by ns-3 are rendered in an interactive frontend for topology playback, queue inspection, and congestion analysis.

## Quick Start

```bash
cd backend
uv sync
uv run fastapi run --port 8001
```

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000` and launch simulations.

## How to Use

1. Click **Configure** and follow the wizard to select the topology and simulation parameters.
2. Click **Run** to start the simulation or load existing outputs.
3. Adjust the playback speed and click **Play** to start the visualization.
4. Click a switch to inspect its queues, then select a queue to plot queue occupancy over time.
5. Select a queue card to highlight the corresponding link.
6. Use the timeline slider to jump to any point in the simulation.

## Repository Layout

- `frontend/`: Next.js UI for topology configuration and visualization
- `backend/`: FastAPI service that launches simulations and serves trace results
- `ns3/`: ns-3 source tree with the custom DCN simulation in `scratch/DCN.cc`
- `workloads/`: workload CDF files used by the traffic generator
- `docs/`: figures, plotting scripts, report, and presentation slides
